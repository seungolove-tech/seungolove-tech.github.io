autotm 은 무엇인가요

autotm 은 운영자 한 사람이 자기 PC 에서 직접 쓰는 개인용 영상 제작·발행 도구입니다. 운영자 본인의 유튜브 채널에 쇼츠 영상을 올리고 성과를 확인하는 데만 쓰이며, 다른 사람에게 서비스로 제공하지 않습니다.

2

Google 계정에서 사용하는 정보

  • 유튜브 채널 기본 정보(채널 이름·ID) — 올바른 채널에 올리는지 확인
  • 영상 업로드와 제목·설명 등록 — 운영자가 검수 후 승인한 영상만
  • 운영자 채널 영상에 댓글 작성
  • 운영자 채널 영상의 조회수 등 통계 — 다음 영상 품질 개선에 참고
3

보관과 공유

로그인 정보(인증 토큰)와 통계는 운영자 PC 안에만 저장됩니다. 외부 서버로 보내거나 다른 사람·회사에 제공하거나 판매하지 않으며, 광고 목적으로 쓰지 않습니다.

4

Google API 서비스 사용자 데이터 정책 준수

Google API 에서 받은 정보의 사용과 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5

연결 해제와 삭제

Google 계정의 타사 앱 액세스 관리에서 autotm 연결을 언제든 끊을 수 있습니다. 운영자 PC 에 저장된 토큰 파일을 지우면 저장된 정보도 모두 삭제됩니다.
